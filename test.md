# Work instruction for Git.
## 1. Creating a repository:
> git init - initializing a repository
## 2. Adding new or changed files and commit
> git add "filename" - adding file to the staging area

> git add . - add every file

> git commit -m "message" - creating a commit

## 3. Working with branches
>git branch - to see current branches

>git branch branch_name - to create a branch

>git checkout branch_name - to switch to a specific branch
